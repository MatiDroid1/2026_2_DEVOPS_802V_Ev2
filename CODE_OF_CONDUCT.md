# Código de conducta

## Compromiso

Queremos que el trabajo en este proyecto académico sea respetuoso y colaborativo para quienes participan.

## Conductas esperadas

- Dar y recibir observaciones sobre el código de forma constructiva.
- Reconocer la autoría de cada integrante y de las fuentes consultadas.
- Declarar el uso de herramientas de IA, como exige la pauta de la evaluación.
- Cuidar los datos sensibles: no compartir credenciales ni tokens.

## Conductas no aceptables

- Faltas de respeto, hostigamiento o discriminación.
- Alterar el trabajo de otra persona para perjudicarla.
- Publicar información privada o secretos del proyecto.

## Aplicación

Cualquier situación que afecte la colaboración se informa al docente a cargo. El objetivo es resolver el problema y continuar trabajando en equipo.
